# RGB 投影与遮挡验证条件

2026-09-07，在首次运行新标定场景之前固定以下条件。它是视觉传感器的几何/栅格接缝，不是 G6 动力学等价预算，也不声称场景已有碰撞物理。

原生 UE 瞬态 Cube 网格组成三个未受光照影响的平面盒：蓝背景中心(425,0,100)cm、尺寸(1,230,230)cm；红目标中心(400,0,100)cm、尺寸(1,160,160)cm；绿遮挡物中心(350,0,100)cm、尺寸(1,40,180)cm。只有 case2 显示遮挡物。记录实际网格局部 bounds、组件世界位姿和 scale；城市装饰在该专用验证模式隐藏，不修改安装或持久资产。真实 PX4/AP 继续提供共同物理状态。

相机固定 640×480、水平90°、零畸变假设，附着 PX4 #2。四个独立场景的相机安装条件分别为：case0 (30,0,100)cm/零旋转；case1 (30,80,120)cm/零旋转；case2 同case0且有遮挡；case3 同case0且绕UE Z轴+20°。每次使用真实捕获位姿投影；不靠事后修改位姿使结果相符。

独立 Python 审计从实际世界几何的8个角投影得到凸包，以声明的光学轴 x=UE Y、y=-UE Z、z=UE X 和像素中心 index+0.5 构造期望区域。遮挡物在目标前面时从红区域扣除绿区域。RGB按主色通道至少60且大于另外两通道1.5倍提取，避免依赖确切色调映射值。

**首次实测前固定的门槛**：二维投影边界的栅格容差为每轴2像素（半像素中心约定、轮廓离散与边缘过滤）；用5×5方形腐蚀/膨胀排除这个边界带。至少500个红色内部像素；内部颜色覆盖率≥99.5%，观测颜色落在预期膨胀区域内的比例≥99.5%。有遮挡时绿色内部同样检查，无遮挡时不得出现超过4个绿色像素。不在失败后增加这项容差；先定位几何、相机、材质或图像处理错误。

`AWksimRgbFixture` 只在明确的可选校准参数下生成；默认产品场景不启用。生成相机图像仍使用现有 SceneCapture2D/异步 GPU 读回，不以像素绘制或屏幕截图冒充传感器。下一步真实四场景运行和 PNG 审计仍须保留，编译通过不等于该验收通过。
