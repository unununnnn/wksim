# 深度相机与点云约定提案（#31 决策输入）

2026-09-07。本提案把已批准的[环境与视觉合同](../2026-09-07_environment-contract-accepted.md)的 RGB 语义直接实例化为深度相机约定，请用户一次性确认；确认前 #31 不进入实施，确认后阈值在各切片运行前冻结。

## 约定（提案）

1. **单位与坐标**：深度单位为米；点云在公共 ENU map 帧携带坐标，原点与权威状态一致；UE 换算限于显示/采集边界。
2. **采样身份**：每帧深度与每个点云携带与 RGB 同族的身份——运行代次、步号、模型时间、载具/传感器/帧身份、实际采集位姿、尺寸/编码、内参、安装外参；墙钟采集/传输时间单独记录。图像、点云与权威状态关联同一采样身份。
3. **编码**：每像素 32-bit 浮点深度（米）；无效深度为 NaN 且有效像素掩码可导出；有效/无效约定在切片中固定。
4. **点云生成**：由已声明内参+安装外参从深度生成；点可组织化或带索引非组织化，均携带同一采样身份与 map 帧坐标。
5. **隔离语义**：丢帧可见，旧 epoch 拒绝，重连只交付当前帧；显示/图像/点云断流不决定物理节拍（沿用合同第 7–8 条，不新增耦合）。
6. **验证**：已知平面/盒几何固定件，距离与投影误差阈值在运行前冻结；不冒称扫描 LiDAR、语义分割或全部视觉传感器。

## 与 #9 的关系

本约定只使用 #9 已批准的**环境/视觉分支**语义，不触及 #9 未决的 DLL/插件 ABI 部分；若用户认为深度点云需要单独的 #9 级决策，请指出差异点，本提案即按答复修订。
