## What to build

使用本机地面站观察实验并与Prometheus任务控制显式交接，双方不会争抢模式。

## Acceptance criteria

- [ ] 复用本机地面站和已有MAVLink边界，明确其与原生DDS任务控制的不同职责。
- [ ] 双栈遥测、载具身份和必要状态可见，端口不与其他运行冲突。
- [ ] 切走任务模式后任务节点撤销持续输出，不自动抢回；恢复需新请求。
- [ ] 正常结束和地面站断开不终止其他用户进程，未经授权不连接真实硬件。
- [ ] 交付实际命令、版本/身份、预期与结果、失败/未验证边界；主代理复核后才能关闭。

## Parallel boundary

本票建议归属：地面站。每个阶段只分配一个写入者；共享消息、调度或生命周期的修改由主代理分配，不能与另一子代理覆盖同一区域。真实SITL/UE测试通过主代理预约隔离资源。模型与推理强度显式gpt-6-astra/low，未经允许不再嵌套委派。
