# G6 参考链 11.0↔11.8 漂移刻画（e0 SLX 11.8 vs ZIP 11.0）

2026-09-08；只读文本对比，未执行模型/厂商程序。承接 [来源核对](model-reference-provenance.md) 与 [补充（e1 一致链与能力盘点）](model-reference-provenance-supplement.md)。不关闭 G6/#23，不提出未经依据的误差预算。

## 结论

**e0 链 11.0→11.8 漂移在语义上仅剩噪声配置一项开放；大气/重力非漂移项；结构等价只能由确定性对照运行行为证明。**

## 逐项证据（可重放）

1. **重力：相同。** SLX 11.8 `Gravity1` 块 `Value=[0 0 9.81]` 与 ZIP 11.0 `<S145>/Gravity1` 注释及 `{0.0,0.0,9.81}` 字面量一致。
2. **大气（ISA）：相同。** SLX 11.8 库引用块 `ISA Atmosphere Model`（SID 12217:1294，参数 g=9.80665、gamma=1.4、R=287.0531、L=0.0065）在 ZIP 11.0 中以预计算形式存在：`<S256>/Constant g/(L*R)=5.2558756014667134`（按 g=9.80665、R=287.0531、L=0.0065 验算到 15 位有效数字一致）、`1//T0=0.00347041471455839`（T0=288.15）、`P0=101325`、`h_trop=11000`、rho0=1.225。字面量集合差异是 codegen 预计算假象，非语义差异。
3. **噪声配置：真实开放项。** SLX 11.8 IMU 噪声参数 `i_seeds=[23093 23094 23095 23096 23097 23098]`、`i_pow=ModelParam_noisePowerIMU*[0.0000005×3, 0.000000002×3]`（SID 12217 子系统）；ZIP 11.0 无这些字面量（0 命中），噪声增益走参数结构 `P.Constant2_Value_{l,m,g}`（NoiseG/NoiseSwitch/NoiseFilter 结构存在）。`ModelParam_noisePowerIMU` 不在 e0 init（掩膜级参数）。**11.0 与 11.8 的噪声功率/种子配置未被证明一致。**
4. **结构规模（弱证据）**：SLX 11.8 共 486 块/40 子系统/23 库引用；ZIP 11.0 有 280 个 `<S>` 子系统引用（codegen 内联编号，不可直接比对）。文本方法不能证明 11.0↔11.8 块级结构等价；结构等价须由确定性对照运行在各探针工况下输出落在预算内的行为来证明（对照本身是判据，不是背书）。
5. 其余差异字面量为界面颜色（0.498039/0.666667）与库版本号（7.2/3.4），无动力学意义。

## 对 #23 执行契约的要求（待 #6/G6 批准后逐项落实）

- 确定性基线必须显式约定噪声处置：两侧均以模型自身开关系列关闭噪声，或把 SLX 侧噪声功率/种子固定为实现侧同值并留存配置证据；默认掩膜值不构成一致。
- 运行前冻结：工况、采样、初态、init 哈希、噪声/种子配置、逐量误差预算（工程来源，不倒用实测）。
