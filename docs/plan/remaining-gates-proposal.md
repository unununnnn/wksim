## #9：可先决定的环境/视觉合同

推荐首个环境切片使用**一份带版本与哈希的静态场景配置**：平面/坡面及一个静态盒障碍，单位米、公共 ENU、原点显式；WSL 在权威物理步查询同一几何，UE 从该配置生成可见几何，UE 坐标换算只在显示边界。这样可验证真实接触，而无需等待渲染帧返回碰撞。坡度、盒尺寸、接触模型和接触误差预算应在该切片实现前固定；尚未获批，也不由本提案假定物理已支持它。

环境消息建议携带 `scene_id/scene_hash/epoch/step/sim_time/valid_from/valid_until`。静态场景加载失败或哈希不一致时在启动前拒绝；配置在当前 epoch 内不可热改。未来动态反馈只在指定权威步提交：缺失/过期必需反馈时冻结所属联合场景并要求显式恢复，不永久复用旧反馈；纯 UE 显示断流仍不冻结物理。该动态策略本轮只是候选，不能声称已有 #8 批准。

RGB 推荐作为独立异步传感器：按已应用的权威状态采集，输出 `epoch/step/sim_time/vehicle_id/sensor_id/frame_id`、实际采集位姿、宽高、编码、K/D 内参和安装外参；采集/传输墙钟另存。消费者拒绝旧 epoch，丢帧可见且不阻塞物理，重连后仅交付当前帧。测试用固定棋盘/遮挡物和已知位姿验证投影与遮挡，保留实际图像及消费者结果；Actor ACK、桌面截图都不能替代采集。

依据：`tickets/19-terrain-collision.md`、`20-rgb-sensor.md` 明确要求有效时间与相机身份/标定。SDK `VisionCaptureApi.py:255–274` 的 `VisionSensorReq` 已含 SeqID、目标载具、宽高、FOV、安装位姿；其 SHA256 `f69a3c50e0d335136b3d83070bf380e7579bd25dfd80ae291a2548d5b79dd7ee`。这些字段支持复用映射，但 SDK 字段本身不提供 wksim epoch/权威采样语义，新增信封是本提案，不是假称厂商兼容。环境票仍依赖 #23 数值票，批准本合同不删除依赖；RGB 分支可独立推进合同及实现。

## #9：DLL 目前能准备合同，不能批准未知 ABI

推荐每个样本独立 Windows 子进程，显式 manifest 固定文件 SHA、ABI 版本、每个函数签名、输入输出长度/单位、步长和已支持能力；旧/新命名分开适配，未证明的布局拒绝加载。生命周期候选为加载→初始化→逐步输入/step/输出→重置为新 epoch→终止/卸载；宿主失败只标记该可选运行失败，多载具联合场景按既有参与者失败规则停止推进。自主核心关闭 DLL 仍须运行。

依据：`DllSimCtrlAPI.py` SHA256 `0a2a30e91fe55590aec198f1e852a6d45d6aa34c029557de62880d0b81cf5420`。同一 `DllInputColls` 在 1237 行声明 double[20]，1294 行重声明 float[20]；1248/1255 行检查 `DllInitPosAngStat` 却访问 `DllInitPosAngState`。因此不能原样抄 SDK 并声称 ABI 已冻结。SDK 1275 行地形 double[15]、1281 行扩展 double[140]、1287 行 UE double[32] 只能当待核对线索；未知字段语义、释放/重置状态及全部扩展 I/O 仍缺契约。此时询问用户“批准旧/新 ABI”没有可审阅的准确对象，应先补可读头/包装源与样本来源链。
