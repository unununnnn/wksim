# 受控地面站界面操作的最新授权

2026-09-09，当前会话在准备并尝试#42地面站控制交接时，用户明确答复：**“全程你自己确认即可”**。

这条最新指令替代[2026-09-08批准记录](2026-09-08-five-decisions-accepted.md)中“界面『切走任务模式』点击仍留用户执行”的分工。主代理可以在既定受控WksimGCS与隔离SITL中自行确认窗口、通过真实界面切走任务模式、再提交新的显式接管请求；不再反复要求用户点击。实际执行者必须记作用户授权的助手自动化，不能记为用户亲手操作。

本轮先用computer-use的实际窗口枚举、激活和原生截图核对UI，再打开模式菜单。QGC的QGCDelayButton保留500ms确认时间；普通click/drag/Return未完成长按。其后使用 `tools/hold_gcs_button.py` 对本次已拥有、处于前台的单一WksimGCS窗口发送0.8秒定向鼠标按下/释放。该补充工具核验PID、内核创建时间、exe路径、窗口标题、可见边界与已观察截图尺寸，并只在当前运行的GUI模式交接阶段接受操作；不构造MAVLink报文，不修改QGC的确认开关。实际输入方式及UI反馈均留档，不能把短点击失败算作完成。

AP的Brake最初被显示列表隐藏，主代理通过实际界面将其设为可见并退出列表编辑。长按确认开关保持启用。确认的是固定已准入固件的版本提示，未执行固件升级。源码/进程/原生包和物理审计仍独立于界面操作。

代码保留部分human命名的阶段标识和旧组件scope，它们是初始候选的历史名称；本轮真实执行依据为上面的最新授权与每场authorized-gui-hold.json中的actor，不作为人工点击证明。该授权不等于新的硬件、许可或对外发布授权；Full中这些既有边界仍按各自具体条件处理。
